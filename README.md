# OOPSBannerApp

## UC1 – Print OOPS to Console

This project implements Use Case 1 of the OOPS Banner App.

### Description
A simple Java program that prints the literal text `OOPS` to the console.
This use case establishes the project foundation before banner formatting
and refactoring in subsequent use cases.

### How to Run
```bash
javac OOPSBannerApp.java
java OOPSBannerApp

```
