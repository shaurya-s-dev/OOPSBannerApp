# OOPSBannerApp

## 📌 Overview
This repository contains the implementation of the **OOPS Banner Application** along with additional **practice problems**.

---

## 🚀 Use Cases Implemented

- **UC1** – Print OOPS to Console  
- **UC2** – ASCII Banner using manual print statements  
- **UC3** – Banner using `String.join()`  
- **UC4** – Banner using Arrays and Loop  
- **UC5** – Improved modular structure  
- **UC6** – Static helper methods for pattern generation  
- **UC7 & UC8** – Advanced improvements and refinements
